# 🩺 VitalCheck AI

VitalCheck AI is an intelligent medical lab report analyzer and dashboard. It allows users to upload a blood test report (such as a CBC, LFT, KFT, Lipid Profile, or Diabetes panel) as a PDF, automatically extracts and structures the lab parameters, and provides a professional health breakdown with tailored recommendations, risk analysis, and doctor questions.

---

🔗 Live Link: https://vitalcheck-ai-f7n4fglecpl9kml3g6hw6f.streamlit.app/


## 🚀 Features

- **📄 Smart PDF Extraction**: Automatically parses text from multi-page medical PDF reports using `pdfplumber`.
- **🧬 AI-Powered Parameter Parsing**: Utilizes **Groq LLMs** (via LangChain's structured output) to reliably extract and structure lab parameters (name, value, unit, normal range, abnormality flag).
- **📋 Holistic Health Analysis**:
  - **Overall Health Score**: An indicator score from 0-100.
  - **Executive Summary**: A plain-language summary of findings.
  - **Abnormal Parameter Flags**: Instant visual cues for parameters outside normal limits.
  - **Personalized Recommendations**: Lifestyle, diet, and habits suggestions.
  - **Family Risk Factor Integration**: Adapts risk levels based on patient-provided family history (diabetes, hypertension, thyroid).
  - **Doctor Discussion Guide**: Formulates relevant, tailored questions to ask at the next check-up.
- **💾 Local History Tracking**: Automatically saves report logs and patient profiles into a local SQLite database (`vitalcheck.db`).
- **📥 PDF Report Downloads**: Generates a clean, print-friendly PDF summary of the analysis.

---

## 🛠️ Tech Stack

- **Frontend/Dashboard**: [Streamlit](https://streamlit.io/)
- **LLM Orchestration**: [LangChain](https://www.langchain.com/) & [ChatGroq](https://github.com/langchain-ai/langchain-groq)
- **Data Validation & Parsing**: [Pydantic v2](https://docs.pydantic.dev/)
- **PDF Text Extraction**: [pdfplumber](https://github.com/samkit-jain/pdfplumber)
- **PDF Generation**: [fpdf2](https://github.com/py-pdf/fpdf2)
- **Database**: SQLite3

## 📦 Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/MS12code/VitalCheck-AI.git
cd VitalCheck-AI
```

### 2. Create a Virtual Environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables
Create a file named `.env` in the root directory and add your Groq API key:
```env
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=llama3-8b-8192
```

---

## 🖥️ Running the Application

Start the Streamlit dashboard by running:
```bash
streamlit run app.py
```
This will start the local server and open the app in your default web browser (usually at `http://localhost:8501`).
